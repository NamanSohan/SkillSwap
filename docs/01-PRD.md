# Tagline

---

# Introduction

SkillSwap is a community-driven platform where people can teach what they know and learn what they don't.

Instead of paying money for expensive courses, users exchange knowledge through SkillCoins and skill-sharing sessions.

The platform aims to make learning affordable, accessible, and interactive.

---

# Problem Statement

Millions of students and professionals want to learn new skills but face several challenges:

- Expensive online courses
- Lack of personalized learning
- One-way learning platforms
- Limited opportunities to exchange knowledge
- No reward system for teaching others

These problems make quality education inaccessible for many learners.

---

# Proposed Solution

SkillSwap solves this problem by creating a peer-to-peer learning ecosystem.

Users can:

- Teach skills
- Learn skills
- Earn SkillCoins
- Spend SkillCoins on learning
- Connect with mentors
- Build their learning profile

Every learner can become a teacher, and every teacher can continue learning.

---

# Mission

To make quality education accessible to everyone by enabling people to exchange skills instead of money.

# User Roles

## Guest

Can browse the website but cannot book sessions.

## Learner

Can search skills, book sessions, and learn from mentors.

## Mentor

Can teach skills, earn SkillCoins, and build reputation.

## Admin

Manages users, reports, categories, and platform activities.
